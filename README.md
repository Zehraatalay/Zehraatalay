## What I'm Building

### Match3-AI-Lab

A Python-based Match-3 environment for developing, training, and evaluating reinforcement learning agents.

- Custom game engine with special tiles and blockers
- Gymnasium-compatible reinforcement learning environment
- Random and Greedy baseline agents
- DQN training and neural network architecture experiments
- PyGame visualization

**Tech:** Python · PyTorch · Gymnasium · PyGame · Reinforcement Learning

[**Explore Project →**](https://github.com/Zehraatalay/match3-ai-lab)

<br/>

### SkillGraph

An LLM-powered application for analyzing candidate profiles and matching them with job requirements.

- Resume and job description analysis
- Skill extraction and comparison
- Agentic workflows using LangGraph
- Explainable job matching

**Tech:** Python · LangGraph · LangChain · LLM APIs

[**Explore Project →**](https://github.com/Zehraatalay/skillgraph)

<br/>

### Retail Sales Forecasting

A machine learning project focused on forecasting retail demand using historical sales data.

- Time-series feature engineering
- Exploratory data analysis
- Gradient boosting and regression models
- Model evaluation using forecasting metrics

**Tech:** Python · Pandas · LightGBM · XGBoost · Scikit-learn

[**Explore Project →**](https://github.com/Zehraatalay/retail-sales-forecasting)
